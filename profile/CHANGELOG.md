# [Ebook Workshop]Change Log

## [Unreleased]

## 版本 [3.12.2] - 2026年8月7日
**！！之前版本数据库将不兼容！！**
添加了不少实用功能的版本，值得升级的选择。
### Added
* 新增【库存】模块，可以以文件形式存储电子书
* 新增 Epub、Txt 文件的在线阅读功能
* 新增设置管理功能，可以通过界面调整部分系统设置
* 新增后台任务功能，可以在系统闲时自动抓取未完成的书籍
* 新增单章内容的抓取功能
* 新增针对网站的字典转换功能，当抓取数据后可以立即根据转换字典替换内容，可以用于应对利用私有字体加密文本的网站
* 新增数据库压缩功能，可以有限的释放浪费的系统空间——大量删除数据后，数据库占用大小不会释放，可以使用压缩功能提前释放
* 新增了直接抓取源代码方式抓取网文的功能，可以应对反无头浏览器访问的网站
* 重构了从网址抓取内容的模块
* 新增内部功能：统计书籍总字数
* 重构线程池，加入自动后台作业的设计
### Changed
* 优化了内部消息的设计
* 优化了用户消息的反馈
* 导出的书籍封面为图片时，可以选择是否嵌入书名
* 优化了书籍信息设置，删除了书籍独立设置字体和字号的信息
* 优化了【消息】等模块的界面显示
* 图书列表改用虚拟滚动实现
* 优化网文管理页面，章节的交互响应
* 稍微优化了重复章节内容的查找效率
* 调整了以登记网站的列表
* 调整生成的 Epub 文件，支持段落间更紧凑的选项
* 优化抓取规则，可以针对网站设置专用UA
* 重构GetDataFromUrl：拆分功能模块
### Fixed
* 修复Txt格式是否缩进功能不符合逻辑的问题
* 修复已存在同名书籍时，抓取网文会没有正确提示的问题
* 修复了初始化网文时，当网文章节过多导致加载数据卡顿的问题（在循环中查找每一章对照网址信息导致）
* 修复了部分在Linux系统下运行不兼容的问题
* ‼️修复当批量抓取含下一页的章节时，若起批章节数大于等于系统最大支持总线程数时，会导致大部分任务无限等待的问题
* 优化错误输出，错误的捕获及处理
